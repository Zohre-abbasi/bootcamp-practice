# Contact App

A contact management application built with React.

## Features

- Add new contacts
- Edit contacts
- Delete a single contact
- Delete multiple contacts
- Search contacts by name and email
- Form validation
- Reusable form components
- Save contacts in Local Storage

## Technologies

- React
- React Hook Form
- Yup
- Context API
- CSS Modules
- React Icons
- Local Storage
